✦ Overleaf AI 설정

overleaf.com 프로젝트 페이지에서만 동작합니다. 글 생성은 이 컴퓨터에 설치된 claude 또는 codex CLI 가 수행합니다. 모델과 사고 수준은 Overleaf 패널 상단에서도 바로 바꿀 수 있습니다.

  3. 이 페이지에서 “다시 확인” 클릭

확장 ID:

AI 백엔드와 모델

CLI 추가 인자는 보안상 확장에서 보내지 않습니다. 필요하면 ~/Library/Application Support/overleaf-ai-host/config.json 에 "claudeExtraArgs": ["--fallback-model", "claude-sonnet-5-5"] 처럼 직접 적으세요. 같은 파일의 "s2ApiKey" 로 Semantic Scholar API 키를 넣을 수 있습니다.

자동 사고 수준은 작업 종류에 맞춰 고릅니다: 교정·번역은 low, 작성·생성은 medium, 검토·오류 해결은 high. 모델이 지원하지 않는 단계는 가까운 단계로 바뀝니다.

글쓰기

자동완성 (회색 제안 · Tab 수락 · ⌘/Ctrl+→ 단어 수락 · Esc 닫기)

자동완성은 백엔드 설정과 관계없이 Claude CLI 로 실행됩니다(도구 없이 텍스트만 생성). 줄 끝에서만 동작하고, 주석·수식·프리앰블·LaTeX 명령을 입력하는 중에는 쉽니다. 한 번 제안할 때마다 CLI 요청이 하나 발생합니다.
